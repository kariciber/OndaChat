Política de privacidad de OndaChat

Última actualización: 14 de noviembre de 2026

OndaChat es una aplicación de música, radio y comunidades de conversación. Esta política explica qué información se utiliza, para qué y cómo solicitar su eliminación. OndaChat se ofrece como proyecto gratuito, sin publicidad integrada.

1. Qué información tratamos

  • Identificación y acceso: Firebase Authentication proporciona una identificación técnica (UID), tanto para sesiones anónimas como para el inicio de sesión con Google. Si accedes con Google, el proveedor de autenticación puede facilitar datos básicos de tu cuenta, como nombre, correo electrónico y foto, para gestionar la sesión. OndaChat no publica tu correo ni tu foto de Google en los chats.
  • Perfil: si guardas un perfil, almacenamos el apodo y el avatar elegido, relacionados con tu UID.
  • Participación: almacenamos los mensajes enviados a las salas, preguntas y respuestas técnicas, apodo mostrado, avatar cuando procede, UID y fecha de publicación.
  • Moderación: se almacenan avisos y denuncias de contenido, identificadores de las publicaciones y su estado de revisión para gestionar la seguridad de la comunidad.
  • Preferencias locales: el navegador o la aplicación guarda en el dispositivo el apodo y la dirección de audio configurada por ti, cuando los facilitas.

No pedimos datos de pago, dirección postal ni número de teléfono para utilizar las funciones descritas.

2. Finalidades

Usamos estos datos para permitir el acceso, mantener los chats y el centro de informática, guardar las preferencias, mostrar perfiles y prevenir o responder a conductas abusivas. No vendemos información personal ni integramos publicidad personalizada.

3. Servicios externos

La aplicación utiliza Google Firebase (autenticación y base de datos Firestore), y la web se aloja mediante GitHub Pages. Estos proveedores pueden tratar datos técnicos necesarios para prestar sus servicios conforme a sus propias políticas.

OndaChat también permite abrir o reproducir emisiones de radio externas, incluido el reproductor integrado de Anti Radio. Al utilizar esos servicios, sus proveedores pueden recibir datos técnicos de conexión conforme a sus respectivas políticas. Si introduces una URL de streaming externa, te conectarás al servidor correspondiente.

4. Visibilidad y contenido compartido

El apodo, avatar y los mensajes o publicaciones que envíes a una sala pueden ser visibles para las demás personas que tengan acceso a esa sala. No publiques teléfonos, direcciones, contraseñas ni otra información privada en conversaciones públicas.

5. Conservación y seguridad

El contenido publicado permanece almacenado mientras sea necesario para prestar el servicio o gestionar la moderación, salvo que se elimine o proceda su supresión. Aplicamos reglas de acceso de Firestore y controles de autenticación; ningún sistema conectado a Internet puede garantizar seguridad absoluta.

6. Tus derechos y solicitudes de eliminación

Puedes pedir información sobre tus datos, su corrección o su eliminación. Por ahora, OndaChat no dispone de un botón de eliminación integral de cuenta dentro de la aplicación. Cerrar sesión no borra automáticamente las publicaciones anteriores.

Para solicitar asistencia, puedes acudir a la página de incidencias y soporte de OndaChat. Las incidencias de GitHub pueden ser públicas: no publiques allí tu correo, UID, datos de identidad ni información privada. Si tu solicitud implica datos personales, pide primero un canal privado de atención; no compartas información sensible en comentarios públicos.

Antes de ampliar la distribución pública se habilitará un método directo y privado para solicitudes de privacidad y eliminación de cuenta.

7. Menores

OndaChat no está diseñada específicamente para menores de edad. La participación en chats y foros implica compartir contenido con otras personas. Las condiciones de edad y supervisión aplicables deberán respetarse.

8. Cambios en esta política

Podemos actualizar este texto cuando cambien las funciones, los proveedores o las obligaciones legales. La versión vigente estará disponible en esta dirección.
